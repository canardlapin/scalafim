# scalafim-inference

Typed perturbation inference for fitted multivariate structures.

`inference` sits directly above standalone `multivar` and Gale. It owns
inferential targets, sampling designs, lawful null and bootstrap actions,
deterministic Monte Carlo programs, latent units, stability summaries, validity
claims, and provenance. It does not refit PCA, PLSC, CCA, RRR, CPCA, or
multiblock models; those fitted geometries remain in standalone `multivar`.

The architectural contract is documented in
[`docs/plans/inference.md`](../../docs/plans/inference.md). The intended public
shape is a serializable immutable specification compiled with small typed fit
capabilities into an executable in-memory program. Unsupported target/design
combinations must fail at compilation, not inside a replicate loop.

## Evidence contract

Phase 0 freezes the external reference evidence under [`fixtures/v1`](fixtures/v1).
The generator is [`fixtures/generate.R`](fixtures/generate.R); it loads the
recorded `multifer` checkout and emits both reviewable TSV files and the
cross-platform Scala mirror used by tests.

The bundle separates three kinds of evidence:

- **Independent analytic oracles:** fixed Monte Carlo counts, known matching
  and sign corrections, and principal angles with closed-form answers.
- **External parity oracles:** unit formation and complete PCA/PLSC ladder
  trajectories generated by `multifer`, including observed statistics, null
  draws, stopping boundaries, p-values, and selected units.
- **Internal laws:** scheduling invariance, reducer associativity, sign and
  subspace invariance, and compiler exclusion tests belong in later Scala
  phases. They are not claimed by this fixture bundle.

The Scala fixture-integrity suite verifies transcription and provenance only.
Algorithm parity begins when the Phase 1 and Phase 2 implementations consume
the frozen expected values.

## Typed core

The first executable boundary is deliberately narrower than the eventual
engine:

- opaque ids, counts, probabilities, seeds, and component indices validate at
  construction;
- `LatentUnit` distinguishes orientable axes from unoriented subspaces;
- `ResamplingDesign[K]` carries its design kind in the type, while validated
  partitions guarantee exact row coverage;
- target and null kinds retain their mathematical meaning, so PLSC covariance
  roots and CCA correlations cannot be interchanged accidentally;
- `InferenceSpec[F, K, N, D]` is immutable plan data with no callbacks, fitted
  values, matrices, resources, or scheduler handles;
- `InferenceCompiler.compile` requires `SupportsTarget`, `SupportsNull`, and
  `SupportsDesign` evidence. Built-in unsupported combinations fail to
  typecheck, while dynamically loaded combinations return
  `InferenceError.UnsupportedProblem`;
- fit, target, null, and compatibility traits remain open so downstream modules
  can add protocols without an untyped registry.

## Exact ordered ladder

The initial interpreter implements the exact shared scaffold for PCA variance
and PLSC covariance inference:

- immutable SplitMix64 streams are derived solely from `(RootSeed,
  ReplicateId)`, so task order cannot change a replicate;
- fixed and batched sequential Monte Carlo use the Phipson-Smyth count and
  Besag-Clifford early non-rejection rule;
- the incremental accumulator computes only recorded batches and emits a full
  receipt with ids, null values, boundary, schedule, allocation, consumption,
  standard error, seed, and algorithm version;
- the pure rolling budget state returns unused draws to later rungs and
  represents exhaustion explicitly;
- one `InferenceExecutor` interprets both `PcaVarianceProtocol` and
  `PlscCovarianceProtocol` through the public `linalg.DenseSvdSolver`
  capability;
- observed roots and deflated statistics match the frozen external fixtures,
  while Scala-owned laws cover execution-order determinism, sign/orthogonal
  invariance, declared repeated-root subspaces, and stop-at-first-non-selection.

## Bootstrap stability

Bootstrap stability is a separate interpretation of fitted latent structure,
not a source of significance p-values:

- row and cluster bootstrap actions derive each sample solely from
  `(RootSeed, ReplicateId)`;
- Hungarian matching aligns replicate components to reference components using
  absolute inner product or cosine similarity, then applies deterministic sign
  correction;
- near-tied axes can be compared as declared subspaces using principal angles,
  while replicate rank loss remains an explicit error/failure count;
- loading and score summaries are keyed by `UnitId`, domain, and stability
  channel, and use bounded-memory online moments rather than retaining
  replicate matrices;
- ambiguity margins and selection frequencies stay visible as stability
  diagnostics and are never converted into ordinary bootstrap p-values.

Bootstrap stability remains distinct from the validated CCA and RRR
inferential protocols below; unsupported requests still fail closed.

## Structured and conditioned randomization

The shared action layer now makes row structure executable rather than merely
descriptive:

- unrestricted, within-block, and within-stratum actions produce validated
  source-row permutations and preserve every declared group;
- whole-cluster permutation preserves within-cluster order and refuses unequal
  cluster sizes, for which no position-preserving action is claimed;
- `NestedPartitions` proves that inner sampling units do not cross outer
  strata;
- nuisance residual randomization operates in the declared whitened row
  geometry as `P_nuisance Y + Pi (I - P_nuisance) Y`, then unwhitens;
- conditioning references, projector dimensions, and required whitening are
  checked before a replicate can run; unsupported combinations return typed
  errors;
- conditioned compiler programs carry `Conditional` validity instead of
  silently inheriting an `Exact` claim.

## Validated inferential families

The final family layer keeps genuinely different hypotheses separate:

- ridge-CCA tests ordered canonical correlations under paired-independence row
  permutation; nuisance-adjusted compilation remains explicitly conditional;
- generalized-eigen inference tests non-negative ordered roots of `(A, B)`,
  permutes the alignment of `A` relative to `B`, and removes a selected root by
  its `B`-orthogonal rank-one term;
- RRR uses normalized held-out predictive gain, with a validated exhaustive
  train/test split and response permutation confined to training rows;
- CPCA inference names one `CpcaBlock`, retains its resolved row and column
  constraints, and provides both a constraint-relative row null and block
  reconstruction removal;
- multiblock consensus inference requires a `BlockPartition`, sums normalized
  block row-Gram operators, independently permutes non-reference blocks, and
  removes selected consensus score directions;
- feature-level null evidence is a sidecar keyed by method, `UnitId`, domain,
  and `FeatureIx`, with Bonferroni, Holm, and Benjamini-Hochberg correction. It
  never derives significance from bootstrap stability.

The frozen Phase 6 evidence bundle is generated by base R and covers ridge
CCA, generalized eigenvalues, held-out single-response RRR/OLS, constrained
SVD, multiblock consensus eigenvalues, and `p.adjust` multiplicity results.

## Execution lowering and exact reductions

Compiled programs lower to immutable `ReplicateJobPlan` values containing only
the problem summary, deterministic replicate assignments, root seed, and RNG
algorithm. They contain no scheduler handles or callbacks, so local, batched,
and future distributed interpreters share one scientific plan.

`ExactRefitReduction` is an optional capability with explicit core, update, and
lift stages. The first concrete instance factors paired tables once with thin
SVDs and computes permuted cross-covariance roots in the reduced row-score
core. Differential tests compare this path against full cross-covariance
refits at numerical precision. Every result records `FullRefit` or the named
proved-exact algorithm in `ExecutionProvenance`.

Reusable associative reducers cover exact exceedance counts and mergeable
online moments. Reordered and chunked floating reductions are tested against
an explicit relative tolerance.

Phases 0 through 6 are implemented; unsupported target/null/design
combinations continue to fail closed.

## Build

```sh
sbt inferenceJVM/test
sbt inferenceJS/test
```

Shared inference code must not import Breeze, dataset, image, Spark, scheduler,
filesystem, or platform-specific APIs.
