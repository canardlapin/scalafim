# Independent ITK convention fixtures

Generated by `tools/generate_itk_oracle.py` using SimpleITK 2.5.6 (ITK 5.4)
and NumPy 2.5.3. `evidence.json` records exact versions, RAS input/output points,
and SHA-256 hashes for the binary artifacts. Regeneration requires only those
Python dependencies; normal R tests consume the retained files without Python.

The grid has unequal dimensions and spacing, nonzero origin, and an oblique
rotation. Each displacement component is a different multilinear polynomial
of voxel coordinates. The affine has a nonzero center, translation, scale, and
shear. The two composites store affine/warp in opposite orders, which produce
different point mappings. All expected points come from `TransformPoint`;
reference images come from `Resample` with linear interpolation.

These small synthetic fixtures are included in the built R package. They test
center handling, LPS/RAS conversion, H5 parameter layout and order, NIfTI vector
layout, interpolation, and pullback resampling independently of this package's
writers. Interior resampling comparisons avoid differences in image padding.
They do not qualify acquired-data registration accuracy or missing FNIRT cases.

Regenerate from the repository root:

```sh
python tools/generate_itk_oracle.py
```
