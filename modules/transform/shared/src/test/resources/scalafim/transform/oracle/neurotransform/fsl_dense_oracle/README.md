# Native dense FSL reference fixtures

Generated by `tools/generate_fsl_dense_oracle.py`, using pinned FSL 5.0.9
`convertwarp` and `applywarp`, without calling neurotransform. The manifest
contains the Docker image digest, exact commands, and file hashes.

Eight cases cover relative and absolute fields for each source/reference
handedness pair. Source and target differ in dimensions, spacing, orientation,
and origin. Native reference images include the asymmetric phantom, three RAS
coordinate ramps, and a two-voxel source-interior support image.

Tests select the fixed native support plus a two-voxel target margin. They
compare source coordinates (3e-5 mm component tolerance), linearly resampled
intensities (3e-6 absolute tolerance), flattened plans, exported fields, and
Jacobians against derivatives of the native coordinate ramps. These tolerances
allow float32 resampling/serialization error while detecting convention errors.

This is dense-field interpretation evidence for the recorded producer, not
FNIRT coefficient decoding or registration-optimizer qualification.
