# scalafim-fmri-ar

Typed temporal-noise estimation and AR/ARMA whitening for fMRI GLM workflows.

The shared implementation runs on both the JVM and Scala.js. It provides:

- immutable whitening plans and pure, row-preserving transforms of both design
  and response matrices;
- checked run and segment layouts, including a distinct noise-estimation layout
  that excludes censored rows without removing them from the whitening axis;
- fixed- and automatically selected-order Yule-Walker AR estimation;
- run-level centering with lag products confined to contiguous uncensored
  segments;
- pair-count autocovariances with strict positive-definite repair before the
  Yule-Walker solve;
- strict characteristic-root validation for estimated and fixed AR filters,
  plus invertibility validation for fixed MA filters; and
- run-aware autocorrelation diagnostics and integration with dense GLS and
  robust AR re-estimation in `scalafim-fmri-fit`.

`NoisePooling.Global` follows the current `fmriAR` contract: estimate each run,
weight its coefficient vector by surviving observations, then re-enforce
stationarity on the pooled filter. `NoisePooling.Run` retains one checked filter
per run. Automatic order search is capped at `floor(n / 5)`; an explicitly fixed
order remains strict and returns a typed error when its requested lag cannot be
estimated.

Parity fixtures in `FmriArParitySuite` are regenerated by
`tools/generate_fmriar_parity.R` from the exact `fmriAR` 0.3.3 revision pinned
in the repository reference lock. They cover fixed AR(1)
through AR(4), automatic order selection, run/censor pooling, ARMA whitening,
and ACF diagnostics. An independent fit receipt also checks two-run censored
estimated AR(2) GLS through the final coefficients, covariance, residual
variance, and degrees of freedom. The adversarial suite covers censor
contamination, short scrub fragments, run offsets and boundaries,
non-positive-definite autocovariances, root-margin enforcement, non-finite
inputs, degenerate runs, and malformed run labels on both supported platforms.
The locked JSON receipts and generated Scala fixtures are hash-checked without
loading R on ordinary pull-request builds, and a scheduled lane regenerates
them from the pinned source checkout.

The module does not currently implement ARMA coefficient estimation or
`fmriAR`'s optional design-aware residual-autocovariance bias correction. The
latter needs the residual-forming design and should be introduced as an
explicit estimation policy; silently applying it to already re-whitened or
robust residuals would give it the wrong statistical meaning.
