# scalafim-fmri-ar

Typed temporal-noise estimation and AR/ARMA whitening for fMRI GLM workflows.

The shared implementation runs on both the JVM and Scala.js. It provides:

- immutable whitening plans and pure, row-preserving transforms of both design
  and response matrices;
- checked run and segment layouts, including a distinct noise-estimation layout
  that excludes censored rows without removing them from the whitening axis;
- fixed- and automatically selected-order Yule-Walker AR estimation;
- run-level centering with lag products confined to contiguous uncensored
  segments;
- pair-count autocovariances with strict positive-definite repair before the
  Yule-Walker solve;
- strict characteristic-root validation for estimated and fixed AR filters,
  plus invertibility validation for fixed MA filters; and
- run-aware autocorrelation diagnostics and integration with dense GLS and
  robust AR re-estimation in `scalafim-fmri-fit`.

`NoisePooling.Global` follows the current `fmriAR` contract: estimate each run,
weight its coefficient vector by surviving observations, then re-enforce
stationarity on the pooled filter. `NoisePooling.Run` retains one checked filter
per run. Automatic order search is capped at `floor(n / 5)`; an explicitly fixed
order remains strict and returns a typed error when its requested lag cannot be
estimated.

Parity fixtures in `FmriArParitySuite` are regenerated by
`tools/generate_fmriar_parity.R` from the exact `fmriAR` 0.3.3 revision pinned
in the repository reference lock. They cover fixed AR(1)
through AR(4), automatic order selection, run/censor pooling, ARMA whitening,
and ACF diagnostics. An independent fit receipt also checks two-run censored
estimated AR(2) GLS through the final coefficients, covariance, residual
variance, and degrees of freedom. The adversarial suite covers censor
contamination, short scrub fragments, run offsets and boundaries,
non-positive-definite autocovariances, root-margin enforcement, non-finite
inputs, degenerate runs, and malformed run labels on both supported platforms.
The locked JSON receipts and generated Scala fixtures are hash-checked without
loading R on ordinary pull-request builds, and a scheduled lane regenerates
them from the pinned source checkout.

## Design-aware residual-bias correction

Autocovariance taken from GLM residuals is biased low: with `M = I - X(X'X)^-1 X'`,
`E[ee'] = M Sigma M`, and the bias grows with the number of regressors. Within a run
`Sigma = sum_k gamma_k S_k`, so the raw estimate is a fixed linear map of the truth,
`E[gamma_raw] = A gamma_true`, where `A` depends only on the design and the segmentation
(run boundaries, censoring, and the per-run centring the estimator applies after
projection). `AcvfBias.matrices` builds `A` per run and the estimator solves
`A gamma = gamma_raw` over the full lag budget *before* truncating to the fitted order and
repairing positive definiteness, exactly as `fmriAR` does.

The correction is an explicit estimation policy, never implicit, because it is only
meaningful for ordinary least-squares residuals of exactly the design supplied:

```scala
val policy = EstimationPolicy.DesignCorrected(design, CorrectionBudget.Fixed(25))
ArEstimation.fitNoise(residuals, layout, options, policy)      // Either[ArError, WhiteningPlan]
NoiseFit.estimate(residuals, layout, options, policy)          // plan + gamma + sigma2 + per-run status
NoiseAcvf.estimate(residuals, layout, maxLag, pooling, policy) // mirrors fmriAR::noise_acvf()
```

`EstimationPolicy.Raw` is the default and leaves every existing entry point unchanged.
`CorrectionBudget.Fixed` is `fmriAR`'s `correction_max_lag`; `CorrectionBudget.Adaptive` is
fmrireg's rule `max(order, min(ceiling, max(5, 2p + 1), floor(min run rdf / 3)))`. A budget
beyond the residual degrees of freedom is reduced to `max(1, df - 1)` (reported on
`AcvfBiasMatrices.budgetCapped`), and a design that leaves none is a typed error. Residuals
that are not numerically orthogonal to the design are rejected with
`ArError.DesignResidualMismatch`. A run whose bias matrix has a reciprocal condition number
below `1e-6` is left uncorrected and reported as `RunCorrection.IllConditioned`.

Parity with `fmriAR` (`acvf_bias_matrix()`, `fit_noise(design =)`, `noise_acvf(design =)`) is
pinned by `FmriArBiasParitySuite` at 1e-10 from fixtures generated by
`tools/generate_fmriar_bias_parity.R`; `AcvfBiasTheorySuite` checks `E[gamma_raw] = A gamma_true`
against an independent analytic expectation. Not implemented: parcel pooling with a design,
ARMA estimation, and carrying gamma/sigma2 on `WhiteningPlan` itself (`NoiseFit` returns them
alongside the plan). See `docs/verification/ar-bias-correction-20261001.md`.
