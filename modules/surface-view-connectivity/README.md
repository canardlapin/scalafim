# surface-view-connectivity

Typed, cross-platform adapter from `scalafim.connectivity` edge spaces and edge
vectors to the renderer-neutral surface-network model. Node placement is
explicit and world-coordinate derivation remains in `surface-view`; estimator
and inference logic do not enter the renderer.

See [`docs/surface-viewer.md`](../../docs/surface-viewer.md) for filtering,
network resource compilation, backend interpretation, and receipts.
