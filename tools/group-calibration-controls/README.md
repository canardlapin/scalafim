# Controlled group calibration

Research tools accompanying `docs/verification/group-controls-2026-09-08.md`.
They are not a production inference API. `controls.py` implements the named
research comparisons; `NativePmCalibration.scala` calls ScalaFIM's ordinary
`GroupModel.mixedEffects` / `GroupEngine.fit` public API. No PLS app fitter is
introduced.

## Reproduce in scratch space

Copy this directory to a writable scratch directory. Scripts write their output
beside themselves. Do not rerun into the historical evidence directory. Install
`requirements.txt` into a dedicated environment. R 4.5.1 with clubSandwich 0.7.0,
metafor 5.0.1 and jsonlite 2.0.0 supplied the independent references. Set
`GROUP_NUISANCE_RLIB` to their R library directory if not on the normal path.

```sh
Rscript --vanilla reference.R .
Rscript --vanilla estimated-reference.R .
Rscript --vanilla feasible-reference.R .
OPENBLAS_NUM_THREADS=1 python3 -m unittest -v test_controls test_estimated
```

These eight tests use retained explicit inputs, fitted quantities, resampling
multipliers, independent R results, metamorphic transformations and analytical
controls. No cross-language shared-seed assumption is used. The estimated-stage
regression compares ScalaFIM outputs retained from the probe with metafor, and
recomputes the Python weighting methods. It does not silently recompile ScalaFIM.

For full fresh native execution, obtain a resolved `groupJVM/Test/fullClasspath`
from the intended ScalaFIM build and a Scala 3.7.4 compiler classpath; write each
as a single platform-separated line. Use the already qualified provider graph
if reproducing this exact candidate. Current checkout HEAD alone is insufficient:
the historical receipt captures the uncommitted group sources and runtime hashes.

```sh
python3 compile-native.py --source-root /path/to/scalafim \
  --compiler-classpath-file /path/to/compiler-classpath.txt \
  --runtime-classpath-file /path/to/group-classpath.txt --java /path/to/java
OPENBLAS_NUM_THREADS=1 python3 calibrate.py pilot > pilot.log
python3 select-confirmation.py > confirmation-selection.log
OPENBLAS_NUM_THREADS=1 python3 calibrate.py confirmation > confirmation.log
OPENBLAS_NUM_THREADS=1 python3 estimated.py > estimated.log
OPENBLAS_NUM_THREADS=1 python3 feasible-weighting.py > feasible-weighting.log
Rscript --vanilla estimated-reference.R .
Rscript --vanilla feasible-reference.R .
OPENBLAS_NUM_THREADS=1 python3 -m unittest -v test_controls test_estimated
OPENBLAS_NUM_THREADS=1 python3 smoke-native.py > native-smoke.log
OPENBLAS_NUM_THREADS=1 python3 replay-estimated.py > estimated-replay.log
OPENBLAS_NUM_THREADS=1 python3 summarize.py > summary.log
OPENBLAS_NUM_THREADS=1 python3 plot.py > plot.log
```

`estimated.py` uses `GROUP_CALIBRATION_JAVA` when set, otherwise `java` from PATH.
The initial fixture `reference-input.json` is explicit and retained; rerunning
`reference.R` regenerates its R side. Full estimated/feasible stages regenerate
their 72 explicit fixtures before the corresponding R checks. Pilot selection is
deterministic and its reasons are retained. Studies are paired across methods,
null/power/center-inversion calculations; these are not independent replications.

The historical experiment contains 642,000 independent studies: 82,000 pilot,
80,000 fresh confirmation, 240,000 estimated-variance studies, and 240,000 fresh
feasible-weighting studies. See the initial protocol and separately declared
follow-up amendment. `summary.json` contains every cell, pointwise binomial
intervals and separately labeled family-adjusted inflation checks. Power uses
the implemented nominal threshold, not a size-matched comparison. Coverage
checks inversion at a true nonzero center, not interval endpoint construction.

The compressed receipt stores text/source files, inputs, aggregate outputs,
independent references, exact input/output hashes, replay audits and reviewed
figures. Bulk native binaries and per-study NPZ files remain in the original
scratch run and are regenerated by `estimated.py`; they are not embedded in the
receipt. `replay-estimated.py` requires that full stage's outputs. Runtime paths
are historical provenance, not portable dependencies. No performance, Scala.js,
application UI, spatial correction or release claim follows from this study.

`verify-evidence.py` checks the retained visual inventory, hashes, counts and
Gaussian positive controls. Rerendered figures require actual new image review
before recording new visual dispositions; do not copy the historical review
to changed images. `unpack-receipt.py` verifies hashes and extracts a receipt.
