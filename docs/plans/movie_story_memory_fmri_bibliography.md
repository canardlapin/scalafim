# Movies, stories, and episodic memory: human fMRI bibliography

**Search cutoff: 16 September 2026.**

This working scoping catalogue contains **63 core research articles** and **3 intrusive-memory extensions**. Article counts are not independent experiment counts.

Scope: human fMRI with movies/video events or written/auditory narratives and an explicit memory task for that material. Encoding-only imaging is eligible when memory is tested later. This is not a preregistered systematic review. Full author lists are abbreviated where necessary; unresolved methods or dataset lineage are marked rather than guessed.

## Core references

### A. Narrative recall and representations

**Chen, J., et al. (2017). Shared memories reveal shared structure in neural activity across individuals.** *Nature Neuroscience, 20, 115–125*.
Source: https://doi.org/10.1038/nn.4450
Stimulus: Sherlock television episode. Memory task: Overt unguided recall. fMRI: Encoding and retrieval.
Dataset: Original Princeton Sherlock.
Note: Original movie/recall sample; distinguish from later independent Sherlock samples.

**Baldassano, C., et al. (2017). Discovering Event Structure in Continuous Narrative Perception and Memory.** *Neuron, 95, 709–721.e5*.
Source: https://doi.org/10.1016/j.neuron.2017.06.041
Stimulus: Continuous audiovisual narratives, including Sherlock. Memory task: Free recall; event correspondence. fMRI: Encoding and retrieval.
Dataset: Includes original Princeton Sherlock.
Note: Several datasets/analyses; Sherlock recall component is not a new independent sample.

**Zadbood, A., Chen, J., Leong, Y. C., Norman, K. A., & Hasson, U. (2017). How We Transmit Memories to Other Brains: Constructing Shared Neural Representations Via Communication.** *Cerebral Cortex, 27, 4988–5000*.
Source: https://doi.org/10.1093/cercor/bhx202
Stimulus: Movies, spoken recollections, listeners. Memory task: Spoken recall and communication. fMRI: Viewing, recall, and listening.
Dataset: Movie–speaker–listener communication.
Note: Contains new communication/listener observations; not simply another analysis of the original 16 recall participants.

**Heusser, A. C., Fitzpatrick, P. C., & Manning, J. R. (2021). Geometric models reveal behavioural and neural signatures of transforming experiences into memories.** *Nature Human Behaviour, 5, 905–919*.
Source: https://doi.org/10.1038/s41562-021-01051-6
Stimulus: Sherlock and its recall transcripts. Memory task: Free recall; semantic geometry. fMRI: Encoding and retrieval.
Dataset: Original Princeton Sherlock reanalysis.
Note: Low-level/high-level distinctions in this model concern semantic/text representations, not visual CNN layers.

**Liu, et al. (2022). Hippocampal-Medial Prefrontal Event Segmentation and Integration Contribute to Episodic Memory Formation.** *Cerebral Cortex, 32, 949–969*.

Dataset: Includes independent second movie-fMRI dataset.

**Lee, H., & Chen, J. (2022). Predicting memory from the network structure of naturalistic events.** *Nature Communications, 13, 4235*.

Dataset: FilmFestival / ds004042.
Note: Independent preregistered behavioral validation uses different films; that validation is not a second fMRI replication.

**Lee, H., & Chen, J. (2022). A generalized cortical activity pattern at internally generated mental context boundaries during unguided narrative recall.** *eLife, 11, e73693*.

## Comparative synthesis: evidence and proposed tests

### Mixed conceptual replication
Evidence: Oedekoven 2017 relative to Bird 2015 and Chen 2017.
Shared reinstatement generalizes; recall–recall superiority was not reliable.
Caution: Task/stimulus differences and a nonsignificant contrast do not establish equivalence.
Discriminating test: Separate identity generalization from transformation; preregister a matched cross-mode replication.
Sources: https://doi.org/10.1038/s41598-017-13938-4

### Identity versus fidelity
Evidence: Developmental amnesia: St-Laurent 2020.
Recall identity can be decodable despite impaired content memory and impaired encoding-to-recall transfer.
Caution: Within-recall and encoding-to-recall classification are not interchangeable.
Discriminating test: Test semantic identity, perceptual lure discrimination, and event-specific cross-decoding in the same trials.
Sources: https://doi.org/10.1016/j.neuropsychologia.2020.107436

### Availability versus conditional detail
Evidence: Sekeres 2021 reminders.
A reminder can increase the probability of retrieving an event without improving its detail once retrieved.
Caution: Does not by itself prove a storage/retrieval dichotomy.
Discriminating test: Fit separate event-availability and conditional-fidelity models.
Sources: https://doi.org/10.1002/hipo.23260

### Delay effects depend on the query
Evidence: Furman 2012.
Recall and recognition have different hippocampal delay profiles.
Caution: Changing task demands and selection of successful trials complicate a unitary consolidation interpretation.
Discriminating test: Cross delay with test type and preserve an unpracticed condition.
Sources: https://doi.org/10.1101/lm.025965.112

### Segmentation versus integration
Evidence: Ezzyat 2011; Cohn-Sheehy 2021; Liu 2022.
Separating event codes can coexist with linking coherent events.
Caution: Pattern similarity, connectivity similarity, and cross-event relational structure are different observables.
Discriminating test: Cross event boundaries with causal coherence and measure both distinctiveness and relational links.
Sources: https://doi.org/10.1177/0956797610393742 ; https://doi.org/10.1016/j.cub.2021.09.013 ; https://doi.org/10.1093/cercor/bhab258

### Minute-scale time versus within-event replay
Evidence: Montchal 2019; Lositsky 2016; Lehn 2009.
Temporal placement, duration, order, and internal replay speed ask different questions.
Caution: Narrative chronology and causal inference can support temporal answers.
Discriminating test: Orthogonalize screen time, story chronology, and causal order using alternative edits.
Sources: https://doi.org/10.1038/s41593-018-0303-1 ; https://doi.org/10.7554/eLife.16070 ; https://doi.org/10.1523/JNEUROSCI.5370-08.2009

### Schemas are not necessarily gist at the expense of detail
Evidence: Masís-Obando 2022; Bonasia 2018.
Schema support and novelty can improve memory through different routes; errors also matter.
Caution: More recalled material is not necessarily more accurate material.
Discriminating test: Score correct details, omissions, and intrusions separately.
Sources: https://doi.org/10.7554/eLife.70445 ; https://doi.org/10.1016/j.nlm.2018.02.017

### The multidimensional gap is narrowing
Evidence: Procida 2025 and 2026.
Object, spatial, temporal, and dialogue memory have already been compared within a movie paradigm.
Caution: 2026 is a reanalysis; cue language and relational demands differ across dimensions.
Discriminating test: Bridge such controlled judgments to free recall and neural reinstatement in the same sample.
Sources: https://doi.org/10.1016/j.neuroimage.2025.121068 ; https://doi.org/10.1007/s00429-026-03184-8

### Event identity is not an unfolding trajectory
Evidence: Methodological inference, not an established empirical finding.
Event averaging can preserve a mean code while removing zero-mean temporal structure.
Caution: Absence of within-event decoding may reflect analysis choice rather than absence of a dynamic memory.
Discriminating test: Report event-level identity and conditional within-event trajectory measures separately.
