# UMVPA M1.05 bounded diagnostics

Diagnostics inspect construction-time metadata cached by AnalysisSpecification;
poison evidence operators and changed callback getters prove no planning-time
neural reads, payload hashing, or statistical fitting. Estimand ID and required
capabilities are captured once. Required capabilities participate in PlanId v2;
available source capabilities are separately inspected and changes require renewed
admission without changing scientific identity.

Descriptions, axes, assumptions, preparation, parameters, capability lists and
blockers have explicit limits and continuations. This bounds returned pages;
sorting capability metadata can still allocate metadata proportional to its size.
Declared, block-verified and fully verified content identity remain distinct.
Diagnostic issues expose code, stage, parameter, observed and required facts and
causal paths. Equivalent execution repairs are separate from scientific changes;
fidelity, estimator, population or claim changes require rebinding. ROI shrinking
is refused as a repair.

Owning gates: mvpaJVM/test and a separate bounded mvpaJS/test. Exact commands,
results, source identities and review are recorded by the integration report.
