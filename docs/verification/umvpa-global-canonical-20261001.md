## Implemented boundary

`GlobalDecompositions` fits typed observation PCA, paired PLSC and regularized
CCA, and neutral SVD of rectangular relations, effect forms or neural forms.
Artifacts retain the actual nominal endpoint spaces, coordinate descriptors,
declared object, preprocessing and metric, provenance, evidence identity and
materialized content identity. Paired artifacts preserve both row geometries
as inspectable receipts and detach the fitted cross form before input scope
expiry. Neutral cross-form SVD declares Euclidean coordinates and no PSD claim.
All generic decompositions use pinned Multivar/Gale kernels.

`CanonicalRunEvidence` and `CanonicalRunSet` preserve real run partitions,
neural domains and temporal preparation. `CanonicalTrainingRuns[P]` binds a
nonempty selection to its nominal partition domain. `CanonicalGlobal.fit`,
`fitNonnegative` and `fitManova` return rich descriptive fitted artifacts directly.
One real run can supply a global fit. Separate assessment methods require
held-out contributors and retain training artifacts, preparation, actual
moment identities, fold receipts and equal-run reduction denominators.
Signed assessments retain the signed numerator and denominator.

Response-learned temporal geometry resolves each exact training scope before
observation acquisition. Every fold fits its training moments before acquiring
its held-out provider; MANOVA assesses only the frozen training frame. The
provider scope expires before closing, and returned artifacts own the numerical
values needed after that scope. Source columns are copied individually without
a neural-square identity. Global canonical fitting no longer constructs a
singleton ROI, generic `MvpaResult`, old canonical input/dataset hierarchy or
legacy scanner outcome. The four old canonical scanner implementations were
physically removed; domain-specific temporal moments and scientific policies
remain.

Metadata shape and capacity checks precede source access. Explicit dense
ceilings cover declared materialization and retained factors. Canonical
admission preserves unknown backend costs, and strict whole-numeric mode
refuses them. These are local admission/accounting contracts, not measured
process memory or complete solver-private workspace bounds. Final allocation
qualification remains a separate epic packet.
