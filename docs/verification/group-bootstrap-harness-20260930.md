## Theory-mandated tests (§7), all shared (JVM + JS), fixed seeds

- **Exchangeable-rank control (§7.1):** observed data and all B draws from a fixed P(θ0), tie-break by an
  independent uniform. Checks: an exact CP 99.9% check of P(p ≤ α) = ⌊α(B+1)⌋/(B+1); a 50-bin χ² below
  qchisq(.999, 49) = 85.35; and a KS distance within the pre-set 1.9495/√R. Default: n8-I-spread-T2-N8 (R = 1000),
  n20-G-rev-T0-N8 (R = 500), B = 99. Heavy: R = 5000, B = 199.
- **Bootstrap-of-z exactness:** known v, τ² fixed at 0, restricted world, z pivot. Same three checks at
  n8-I (R = 2000) and n20-G-rev (R = 1000); heavy: R = 20000, B = 99 (1029/20000 = .0515 against an exact .05).
- **Pathwise invariances with paired variates**, every scheme, three studies: (y, v, b0) → (cy, c²v, cb0) for c = 2
  and 3.7; X → XL with c → L′c; subject permutation with its variates; p(y) = p(−y) with negated normals and identical
  χ² draws (bit-exact). k and f are identical, and every T* agrees to 1e-12 / 1e-9.
- **Sign flip (§7.3):** literal n = 8 data (unequal v, an exact zero, an exactly tied \|y−b0\|); every orbit point
  has #{g: p(gy) ≤ .05} ≤ 12 (both fixtures sit exactly at 12). The fixtures include one with injected failed transformed
  fits, and 25 random Model-J orbits with and without failures are checked. Monte Carlo sign flip at n = 20: 16/300.
- **PM identity (§7.4):** q = 1 within 1e-12 at interior roots, and q ≤ 1 at the boundary. The native mKH statistic
  equals the unscaled Wald statistic within 1e-7, and the harness PM/mKH T matches native `GroupEngine` on one study of
  each of the 90 core cells to 1e-7. Restricted PM satisfies Q0 = n − p0 and c′β̂0 = b0, including p0 = 0.
- **Controls (§7.6):** only the unrestricted uncentred bootstrap is discriminating. It fails as predicted: 0/150
  null rejections and 0/150 power rejections at n20-I-flat, where B-plug has 56/150 power; and 0/100 against B-plug's
  37/100 at n20-G-spread-T2-N40. The four hypothesis controls (recentred, known-v/frozen-τ², omit-u*, ν swap) are wired and
  checked for distinct behaviour. Their rates are pilot material and are not asserted.
- **Other:** df admission; CP edge conventions and frozen integers; outcome logic; p-bound accounting; fixed-B failure
  counting with poisoned draws; B-EB degeneracies (ν = ∞ gives B-fixV, d0 = ∞ gives s0²); B-fixV terciles; one
  full `StudyRecord` per family, including H and AR(1) stress.

## Deviations and interpretations (for review before the manifest freeze)

1. **Kernel, not the prepared native path.** `GroupGlm.prepare/meta` are `private[group]` in
   `scalafim.fmri.group` and cannot be reached from `scalafim.group.research.bootstrap`. The harness therefore uses its
   own allocation-free WLS + PM kernel, which the restricted fit needs in any case. The kernel is checked against native
   `GroupEngine` on all 90 core cells (1e-7) and against metafor (1e-8). The native baseline uses the public API, one
   call per design with studies as sample columns; the probe measured this path at the prepared-kernel cost.
2. **Stress cells:** the declaration lists the stress kinds but not every dimension. Harness choices, recorded in
   `cells.json`: leverage uses n20-G-flat, T{0,.2}, ν8; low-ν (3/4/5) and declared-df 4/16 use G-rev-T0; dominant precision, t3,
   lognormal and AR(1) use I (flat, or dom); the dominant-precision cells read "10 vs .04" as subject 1 with precision 10
   (σ² = .1) and the others with precision .04 (σ² = 25); AR(1) uses a length-10 series with an intercept plus a block
   regressor and nominal df 8. Cell IDs carry a stress tag: `S-<kind>-n…`.
3. **Stream key refinement:** each key (root, cell, study, stream) is split into independent lanes (u*, e*, χ²,
   posterior, …), so paired schemes consume identical variates. Power studies take every component from the power root.
4. **Known-v / frozen-τ² control:** u* is drawn from the restricted τ̂0²; T* is the Wald statistic with τ² frozen at the
   observed unrestricted τ̂², with no refit and scale 1. The unrestricted recentred bootstrap is included as a descriptive
   control.
5. **Tolerances:** T* parity uses relative 1e-8, as the task requires (stricter than §7.5's 1e-7). The sign-flip
   "≥" uses a relative tie tolerance of 1e-10 in both Scala and R, because mathematically tied statistics differ in the
   last bits. This only raises p, so each rejection set is a subset of the exact one and the level stays ≤ α. The PM
   boundary is τ̂² = 0 when Q(0) ≤ target, as in native code (§2 writes "<"; the difference has probability zero).
6. **KS:** v2 replaced v1's continuous KS with the exact discrete rank law. Both the declared checks (CP + 50-bin χ²)
   and a KS distance with a pre-set tolerance are implemented.
7. **Decision precedence** is Adopt, then Decline, then Bound, then Unresolved. Read literally, "Decline: any cell Fails"
   means Bound can only apply when the cells outside the sub-family are Unresolved. The owner should confirm this reading.
8. **One pilot-like run, since removed.** An opt-in heavy test (log `bootstrap-harness-jvm-heavy.log`) printed
   descriptive rejection rates for all schemes on three declared cells: C-n80-DG-Vrev-T0-N8, C-n20-DI-Vspread-T2-N8 and
   C-n8-DG-Vrev-T2-N8. It used 400 harness-seed studies with B = 199. The test was then deleted because it approaches
   pilot work. Those numbers are not evidence, are not reported here, and must not inform cell selection.

## Limitations

- No pilot and no confirmation. Nothing here is a calibration claim about any candidate.
- Mutation runs are JVM-only; the suites themselves run on both platforms.
- Normal and gamma draws use `log`/`sqrt`/`pow`. JVM and JS produced identical manifests and identical rank-control
  counts, but IEEE does not guarantee bit-identical `log` across platforms.
- The p-value of the native and HC3 baselines uses the production t distribution (accuracy ≈ 1e-7, integer df).
- Default Monte Carlo sizes are small, to keep JS fast. The larger checks are opt-in:
  `-Dscalafim.group.bootstrapResearch.heavy=true`, JVM only, since JS system properties are empty. The last heavy run
  passed: 57 total, 56 passed, 1 skipped (the writer).
- The kernel's per-fit cost was not re-measured against the probe.
