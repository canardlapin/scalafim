## 3. What is refused

- **ML public outputs require `ExactShape` + `PreparedBasisResidual`.** Yes. Any other mode returns, before any read, `Left(ProfileFitError.TrialOutputMlIntent(mode, evidence))`. Observed with `CorrectedReference`: `Left(TrialOutputMlIntent(CorrectedReference,PreparedBasisResidual))`, message "native ML public output requires ExactShape/PreparedBasisResidual; requested CorrectedReference/PreparedBasisResidual". `PreparedBasisResidual` is the default evidence argument, so only the mode must be set explicitly.
- ML at alpha = 0: `Unsupported("ML requires positive-alpha trial events")` (condition arm never carries ML).
- `ProfileHrfPlan.fromFixed` (the fixed-condition OLS retention route; the design document calls it `fromFixedCondition`) refuses AR whitening: "fixed condition OLS retention does not support AR whitening". **The PHRF condition arm under O1 must use `fromTrialEvents(alpha = 0)`, i.e. the compact route**, which accepts `Shared` whitening. S3 should bind to this route (it also needs `observedAdmission`).
- Estimated AR inside the fit is refused ("estimated AR coefficients are not implemented"); externally estimated, fixed, global coefficients are accepted if `FitConfig` and `WhiteningPlan` agree (coefficients, initial-condition policy, run segments). This is what O1 prescribes.
- Unsupported by `validateConfig`: voxelwise or iterated AR, censoring, robust, volume weights, nuisance projection, missing-data policy other than `Error`; `DataSelection` other than a full time frame.

## 5. Blockers and notes

- B1: closed (executed, not just callable).
- B2: resolved by O1; the working path is fixed global AR via `CanonicalTemporalWhitening.Shared` plus matching `FitConfig`. The PHRF condition arm must go through `fromTrialEvents(alpha = 0)` (not `fromFixed`).
- Design-doc correction: `fromFixedCondition` is `fromFixed`; the baseline needs care: `BaselineBasis.Constant` already emits one intercept per run, so a generator nuisance matrix that includes its own intercept column makes the nuisance rank deficient and every trial preparation fails with "reference node 0 nuisance/condition release is rank deficient (31 columns)" at every alpha (first spike attempt). The spike drops the generator's intercept column per run (identical span); S1/S2 must do the same or build a baseline with no intercept term.
- Non-Accepted voxels are a real fraction here (condition 17.5 %, trial 20 % at SNR 0.5/1.0): the runner must record them as typed `Refused`, per section 2.3, and the trial public outputs return `DecodeRefused` rather than amplitudes for them. [2026-10-02: the 17.5 % and 20 % were computed under a half-TR-shifted SamplingFrame; superseded, re-measure in S10]
- Pre-fit AR estimate depends on the FIR model (0.284 vs 0.375 against truth 0.3); S2 should settle the pre-fit specification before the pilot (a tolerance of 0.3 is not met by the spike pre-fit in the trial cell).
- Not exercised in S0: LOROCV held-out prediction (B3), PHRF-can, per-voxel timing under multiple workers, JS execution of the smoke (JVM test scope only), and `tr_aligned_onsets` issues for GLMsingle.
