# UMVPA M1.06 local predictive admission candidate

The local Alder provider adds IdentifiedRows with checked native Long IDs,
requested selection order, disjoint fixed Train/Validation/Test routes and
explicit exhaustive/subset coverage. Its declared-source summary fingerprints
include ordered root and selected IDs and role. There is no public arbitrary
role promotion or Refit minting. Generic payloads are not deeply frozen.

The consumer binds an immutable full scientific-key/native-ID map to the axis
and declared source. A separate declared metadata identity includes that map.
It accepts already materialized DMat inputs and targets and budgets copied
numeric cells using Long arithmetic before allocating row arrays. The receipt
counts successful adapter numerical copies; it is not a total object-heap or
payload-verification receipt. Operator-table conversion is explicitly refused:
the previous feature-square identity workspace is not admitted. Matrix-native
Ridge remains unavailable, so this is a limited materialized integration surface.

CrossFitDesign exact assessment partitions and ordered complementary analysis legs
are checked before rebuilding FixedPartitions.once. Alder's
fromDesignForPopulation binds expected training fingerprint AND ordered RowIds
at actual split time, before encoder fitting, while retaining stage seed derivation.
The native scientific receipt remains separate from Alder's actual-stage receipt.
Reordered, foreign-member and changed-revision populations are refused.

Consumer scenarios use public Alder Learner, target-blind Transform and target-aware
cross-fitted FeatureMap.learnWith. An independent recording terminal learner checks
ordered OOF ID/input/target/metadata tuples and own-target exclusion. The serving
artifact uses all-row fitted state, distinctly from OOF rows. Artifacts and audit
source policies are retained; Use.Test fitting and target access by a target-blind
input fail to compile. Poison operators prove the unsupported direct path reads
nothing. Budget overspend is refused and extreme dimensions use Long arithmetic.

Provider dataJVM/test and dataJS/test, and consumer owning JVM/JS suites, require
-Dscalafim.alder.build=/private/tmp/scalafim-umvpa-20260929/alder-fixed-rows.
Exact results are recorded in the integration report. Default pinned Alder lacks
these new APIs. Upstream publication, immutable pinning and canonical consumer
admission remain outstanding; M1.06 is not complete.
