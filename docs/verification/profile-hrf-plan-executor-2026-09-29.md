## Execution contract

`ProfileHrfFit.prepare` checks the full ordered temporal frame, declared voxel selection, exact fixed IID or fixed shared AR preparation, decoder grid and the executor's 1..256 voxel/block and 1..8 worker budget before lowering a trial design or reading any response. Trial random-effects ML is refused before any trial expansion because the scalar determinant path lacks the shape jets needed by that criterion. Unsupported missing data, weighting, robust, censoring, projection, estimated AR, and nondefault LSS settings are explicit refusals.

Fixed shared AR identity includes the complete AR coefficients, an empty MA component, the initial-condition policy, and run segments. A zero-column DCT baseline is admitted by validating the temporal layout without constructing a dummy design. Shape-prior precision is checked for exact symmetry and a nonnegative spectrum with no negative-eigenvalue tolerance before the decoder sees it.

`ConditionMeans` from trial events constructs a condition-valued event term in the declared label order and lowers `ExpandedConditionDesign` directly. Its compact route requires an observed-family admission tied to the actual source term, frame, basis, precision, nuisance matrix, and whitening plan. A fixed condition `FitPlan` uses the existing condition OLS retention and its observed-family admission. Positive alpha lowers `ExpandedTrialDesign` once, builds one `TrialBandedPreparation` and node bank, then creates a fresh mutable worker per run.

The trial reader gathers each column from the time-major whitened response block into contiguous time storage before encoding it. The decoder's amplitude vector has one entry per condition. Its continuous returned coordinates are passed to `TrialBandedObjective.readout(ExactShape(...))` for the final conditional trial amplitudes and penalized energy. This response-dependent result has a distinct type from the response-independent `TrialReadout`; the public normalized query contract remains PHRF-11.

The sink receives blocks in selected-axis order, with `VoxelBlock.start` indexing that selected sequence and payloads naming actual voxel IDs. Reads are at most 256 voxels. The shared `run` calls portable `BlockExecutor.runSequential`; `execution.workers` is an upper bound and the receipt reports the one actual worker. On JVM, `ProfileHrfFitParallel.runParallel` uses the existing `ParallelBlockExecutor` for the positive-ridge trial route. It requires exactly one distinct caller-owned reader for each worker that can run at the requested block size, validates every reader's dataset descriptor before any read, and never closes one. Immutable trial preparation and node-bank factors are shared; each worker owns its objective, decoder, response buffer, reader, counters and output block. The executor limits each window to eight blocks, coordinates ordered sink delivery, and releases payloads after receipts. Fixed and compact condition routes remain sequential.

The runner checks cancellation before reads, between voxels, and before delivery. A sink failure stops later windows. Errors include delivered and attempted counts, and previously delivered blocks remain partial. JVM failure progress aggregates the stopped workers' actual state, including blocks already in flight in the first window. Reader, cancellation callback and sink exceptions are typed. The caller owns reader and sink lifetimes.

Fixed-route reader and cancellation-callback exceptions are returned as typed `Dataset` and `Backend` errors with partial progress. Provenance version 2 records event timing, fixed event records, dataset run labels/time-axis blocks and metadata, exact basis lags and sampled values, and coefficient-map jets at the basis grid nodes. It is a preparation-time snapshot of the inputs used for lowering.

For trial fits setup also reports the retained bank estimate and the `rows × trials × rank` dense expansion size that exists transiently during lowering. ## Owned-pool lifecycle correction

The JVM executor now shuts down and cancels on failure, then waits against a monotonic cleanup deadline of at most one minute. An interrupted wait clears the interruption for another wait and restores the coordinator's interrupt flag only after cleanup. Normal processing has no deadline. A final success or error means all owned workers have stopped. If a worker ignores cancellation past the cleanup deadline, the executor returns `ExecutionError.WorkersStillRunning` with the original error, ordered accepted block IDs, and an owned `ExecutionTermination` handle. The caller can check `isTerminated` or use interruption-tolerant `awaitStopped`; no sink delivery occurs after this nonfinal return.

The fit adapter returns `ProfileFitError.WorkersStillRunning` in that case. It carries the original executor error, accepted `ProfileFitReceipt`s, setup, provenance, and a `ProfileRunTermination` handle. It exposes no attempted, decoder, trial or status counters while a worker is active. The caller must keep every reader available until the handle confirms termination. `awaitFinal` joins the pool and then captures the final typed error and immutable progress once; repeated calls return the same snapshot. The termination wait never returns early on interruption. `awaitFinal` holds its monitor while joining and serializes concurrent callers; it is not a bounded wait API. Poll `isTerminated` for nonblocking observation and retain the reader lifetime until the join finishes. The cleanup timeout seam accepts only 1..60000 milliseconds, with 60000 as the default.

Latch-controlled JVM tests cover a real trial reader held after acknowledging worker interruption while a rejecting sink interrupts the coordinator. A prompt release produces an ordinary final sink error only after reader exit; a deadline expiry produces the nonfinal outcome while the reader is active and a stable final error after release. Generic tests also cover a prior accepted receipt before sink rejection, caller interruption with workers ignoring cancellation, restored interrupt flags, no later sink delivery and invalid cleanup timeout values. Existing worker/chunk and scientific checks remain in the scoped suites.
