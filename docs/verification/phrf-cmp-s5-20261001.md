## PenaltyScale derivation (real PHRF canonical shape)

`PhrfCanonicalShape.derive`: the point of the Gaussian chart whose unit-peak kernel is closest in squared error (0.1 s grid over
[0, 24 s]) to the peak-normalised `Spmg1` response that the LSA/LSS/rLSS regressors use. Deterministic nested grid search (41 x 41
over the chart, four zoom rounds). Result: **tau = 5.44994 s, sd = 2.18548 s (logSd 0.78183), squared error 0.89293**; a local-minimum
test perturbs each coordinate by 1e-3.

`PhrfPenaltyScale.derive` evaluates S4's `p = kappa^2 (1 - 1/n_c) lambda` on a real dataset: `phrfNorm2(i)` is read from the PHRF
`TrialBandedPreparation`'s packed Gram blocks at the canonical shape's basis coefficients (whitened with the shared plan;
`PenaltyScale.phrfNorm2`), `rlssNorm2(i)` is the squared norm of the whitened canonical column of the shared native inputs.

| Dataset | kappa^2 | centring `1 - 1/n_c` | factor | spreads (shape, centring) |
| --- | --- | --- | --- | --- |
| Real harness `T-TX-fast__d0000` (3 voxels, 48 trials per condition) | 1.03592 | 0.97917 (47/48) | 1.01434 | 0.000, 0.000 |
| Synthetic PHRF-model data (12 trials per condition) | 1.03164 | 0.91667 (11/12) | 0.94567 | 0.000, 0.000 |

The PHRF squared-norm sum equals the directly convolved, whitened regressors to 6.7e-7 relative. The pilot's rLSS arm must be built
from `PhrfTrialRunner.rlssSettings(inputs, prep)`, which calls this; a test runs `TrialNativeRunner.run(Rlss, ...)` with those
settings and asserts that every final-map native penalty equals `scale.penalty(lambda_k)` bit for bit and differs from the
unscaled lambda. `PenaltyScale.Identity` is a placeholder in tests only.

## Fairness

- PHRF, PHRF-can and rLSS share one LOROCV shell, one fold score and one amplitude predictor (S4's; called through public entry
  points). The held-out whitened response and the held-out whitened nuisance are the same `TrialNativeInputs` rows rLSS is scored on.
- Selection: largest mean fold score, ties to the smaller alpha (`Lorocv.select`). The nine alphas are typed `PositiveAlpha`.
- The training fit of a fold reads only its own runs: rows, events, baseline columns (the held-out run's columns are dropped),
  whitening segments and sigma2 (`CommonPrep.sigma2Training`). The pre-fit rho is estimated once from all runs and shared
  (declared, design 2.2).

## Ambiguities resolved

1. **PHRF canonical shape.** The design says "the canonical shape" for both PHRF-can and the penalty scale without defining it in
   the Gaussian family. Defined as the squared-error-closest chart point to the peak-normalised `Spmg1` response (above).
2. **Which voxels the fold score pools.** All delivered voxels, whatever their decode status: a fold fit decodes a point for every
   voxel, and dropping voxels per (fold, alpha) would let the pooled voxel set vary with alpha. A fit that delivers no readout fails
   the dataset typed. Only the final fit turns a non-`Accepted` status into a per-voxel refusal.
3. **Prediction units.** Held-out signal = sum of (training amplitude of the same stimulus, the training condition mean for an unseen
   stimulus) times the held-out trial regressor at EACH voxel's own decoded shape, in raw-coefficient units (`TrialBandedReadout.trialAmplitudes`),
   then whitened with the held-out run's one-segment plan. Verified against the held-out data from the true shape (R2 = 1.0).
4. **Fold fits use the legacy `run` readout; the final fit uses the public ExactShape outputs.** The public outputs would add about
   29 core-ms per voxel to each of the 36 fold fits; the legacy readout is the same conditional solve at the decoded shape (checked
   to 2.4e-12 against the public output, and to 4.8e-14 against a dense solve). The final fit does both (design 2.2): the run for
   terminal ML evidence and the receipt, the public outputs for the amplitudes.
5. **sigma2.** Folds: `CommonPrep.sigma2Training(trainRuns)`; final: `prep.sigma2All`. On noise-free data the borrowed noisy-sibling
   value is inconsistent with the data and the determinant term of `J = E + sigma2 D` pulls the decoded sd (observed 0.28), so the exact-data tests
   use sigma2 = 1e-6, which makes the shape the profile minimum (error 1e-5).
6. **Status mapping (design 2.3).** `ProfileFitError.*` at plan/prepare/run/outputs is `Refused` (all voxels), harness and
   preparation failures are `Failed`, a decode status other than `Accepted` is a per-voxel `Refused("decode_<status>")`.
7. **PHRF-can has no decoder.** It builds the banded preparation and a 3 x 3 node bank (the smallest that brackets the canonical
   point), freezes `ProfileTrialReadout` at the canonical coordinates, and reads every voxel conditionally. It is a timing probe: not scored, not hashed with PHRF.
8. **The alpha-0 limit.** The design defines it: alpha 0 is the condition-means route. It is tested on the fixed-shape readout
   (alpha -> 0 equals the native condition-means GLS fit; alpha -> infinity equals native LSA), not on the ML decoder, whose shape
   would differ from the canonical one.
9. **No S11 fixture covers the PHRF trial route** (S11 covers CAN, INF3, FIR, LSA, LSS, rLSS). The checks above are against
   independent computations instead.
10. **Platform difference, not a defect.** For a zero-signal voxel the decoder returns `Boundary` on the JVM and `BudgetExceeded`
    on JS; both are typed refusals and the test accepts either.
