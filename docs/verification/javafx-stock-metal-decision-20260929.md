# Stock JavaFX Metal decision — 29 September 2026

**Decision: reject/defer stock Metal** for the tested JavaFX 25.0.4 and 26.0.2 macOS arm64 closures. Both runtimes generated all 48 synthetic frames with `MTLPipeline`, `prism.noFallback=true`, and no module mutation. The unchanged independent color oracle passed only **39/48** fixtures and **23/32** face-permutation comparisons on each runtime. A passing snapshot process is not a passing color gate. ## Public support boundary

`JavaFxRuntimeCapabilityReceipt` records requested and observed Prism pipelines, fallback flags, module mutation arguments, Java/OS versions, module code sources, and JAR hashes. Its `stockMetalFailures` method is **runtime/packaging preflight only**; an empty failure vector does not admit the renderer. The separate `JavaFxStockMetalAdmission.assess` API requires an observed runtime receipt and expected artifact hashes. It returns typed `Runtime` or `UnqualifiedClosure` refusal, with no currently constructible product approval. The color failure is a source- and host-bound scientific decision in this report, not an inference from a JavaFX version string. An ES2 observation is a runtime refusal for *stock Metal* and does not remove the general JavaFX Scene3D/ES2 capability. No platform becomes qualified by selecting Metal or changing a JavaFX version.

Because the color gate fails, the downstream bilateral beta/FIR, 1,200 same-face picks, 20 alternating updates, full zoom/AA/lighting/underlay visual review, sustained resources, and packaged consumer gates were not run as admissions here. Earlier similar screenshots and pick counts remain exploratory evidence. Alternative-provider Mote `bd-01M3QQ8EBSWQA0V65NYQATJXB3` is bounded to consuming the existing renderer-neutral `SurfaceRenderPlan` and passing the same independent oracle and native/product gates before any JOGL/OpenGL or other backend is admitted. The current decision does not implement that provider or alter scientific scalar semantics.
